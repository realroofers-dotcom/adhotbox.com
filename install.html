Honest answer

Is there a program that installs it for me?

No, and it is worth knowing why.

Nothing you download can write to your web server. To do that it would need your hosting password — and a program that asks a stranger for those is indistinguishable from a scam. That boundary is deliberate and it protects you.

What we did instead was remove the work. One line in your footer and the advertisements place themselves — no second paste, no code blocks, no editing pages. That is as close to automatic as anything can safely get.
