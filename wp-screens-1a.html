In the editor

Add a block, search for AdHotBox, pick a size. That is it.

In a sidebar

Appearance, then Widgets, then AdHotBox.

Anywhere text goes

[adhotbox size="card"]

In a theme file

<?php adhotbox_slot('rail'); ?>
